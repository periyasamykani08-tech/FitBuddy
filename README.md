# FitBuddy - AI Fitness Plan Generator using Gemini Models

FitBuddy is an AI-powered fitness assistant that creates personalized fitness plans using Google Gemini.

### Features
- Personalized diet and workout plan
- BMI calculation and suggestions
- Chat with AI fitness coach

### Tech Stack
- Google Gemini API, Python (app.py), Java (app.java), Javascript

### How to Run
1. Clone this repo: git clone https://github.com/periyasamykani08-tech/FitBuddy
2. Add your Gemini API Key in app.py
3. Run python app.py
